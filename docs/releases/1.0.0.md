# Omascribe 1.0.0

Omascribe now offers Source, Split and Preview views, with a live Markdown
preview and persistent view preferences.

## Writing and preview

- Switch views using the centered footer selector. Source stays instantiated,
  preserving the document, cursor, selection, undo history, modified state and
  recovery when changing views.
- Split places source on the left and preview on the right. Drag the divider
  to resize the panes; view mode and proportion are remembered per profile.
- Scroll either pane to synchronize their relative scroll positions. Resizing
  and preview updates retain the position chosen by the user.
- Preview renders unsaved edits, undo/redo, recovered drafts and local control
  changes using Qt's native Markdown support. It shares the source font, theme
  and text scale, supports selection and copying, and scrolls wide content
  horizontally.
- Relative images resolve against the current file's directory, including
  after Save As. External links use the existing system handler.
- Separate paragraphs, lists, code blocks and tables with font-relative
  margins. Add extra space before headings while keeping wrapped lines,
  explicit hard breaks and code lines compact.
- Find and Replace in Preview reveal Split view. Formatting and undo/redo
  shortcuts require source focus; save, open and print remain available.
- Local control state includes view mode and split proportion for screenshot
  evidence, without adding commands or changing document protections.

## Verification

The complete local harness passes 45 QtTest results and seven release workflow
tests, with no unexpected QML diagnostics. Screenshots cover Source, Split and
Preview in light/dark themes, the minimum window at 4/3 text scale, and a
fixture for paragraph, heading, list, code, quote and table spacing.

Checks cover profile isolation and preference persistence, live rendering,
local images and Save As, selection/copy, undo/redo, recovery, search from
Preview, divider resizing and bidirectional scrolling. The standalone Arch
package is built from the immutable GitHub tag archive and verified separately.

Qt Markdown extensions for formulas and diagrams are not included. Scroll
synchronization follows percentages rather than an exact line correspondence.
Native portals, printing, IME, desktop focus and physical monitor fractional
scaling still require manual desktop verification.

## Packages and AUR status

The GitHub release includes `omascribe-1.0.0-1-x86_64.pkg.tar.zst`,
`omascribe-1.0.0-1-aur.zip` and `SHA256SUMS`. The AUR recipe contains a standalone
PKGBUILD, `.SRCINFO` and install script, pinned to the release source checksum.

AUR publication remains pending: the maintainer has no AUR account or registered
SSH access, and reported that new registrations are closed. The recipe is
prepared and locally verified; it has not been published to AUR.

Install the Arch package with pacman, or run `bin/install` from a checkout as
your ordinary user. GitHub pushes alone do not update an installed app. See the
[packaging guide](https://github.com/RolandDumit/omascribe/blob/v1.0.0/docs/packaging.md).
